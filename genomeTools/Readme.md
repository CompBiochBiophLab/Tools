# Genome tools

Tools to perform tasks in genome bioinformatics, including small tasks with protein or gene sequences

## Environment

Use the folder environment file before running the notebooks:

```bash
conda env create -f genomeTools/environment.yml
conda activate tools-genometools
```

When the environment is no longer needed, remove it with:

```bash
conda deactivate
conda env remove -n tools-genometools
```
