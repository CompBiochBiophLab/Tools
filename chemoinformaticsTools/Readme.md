# Tools for chemoinformatics tasks.

Several tools to run tasks for chemoinformatics analysis.

## Environment

Use the folder environment file before running the notebooks:

```bash
conda env create -f chemoinformaticsTools/environment.yml
conda activate tools-chemoinformatics
```

When the environment is no longer needed, remove it with:

```bash
conda deactivate
conda env remove -n tools-chemoinformatics
```
